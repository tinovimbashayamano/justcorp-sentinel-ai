# Model Comparison Report

## Objective

This report compares the baseline SGD Logistic Regression model, XGBoost model, and LightGBM model trained for the JustCorp Sentinel AI fraud detection pipeline.

## Models Compared

The following models were compared:

- Baseline SGD Logistic Regression
- XGBoost
- LightGBM

## Evaluation Metrics

The models were compared using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Average precision / PR-AUC

Because the dataset is highly imbalanced, PR-AUC, recall, precision, and F1-score are more informative than accuracy alone.

## Results

The values below were generated by the comparison script after running the available model metric files.

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC | PR-AUC |
|---|---:|---:|---:|---:|---:|---:|
| Baseline SGD Logistic | 0.778576 | 0.109218 | 0.744496 | 0.190491 | 0.845530 | 0.392479 |
| XGBoost | 0.863498 | 0.176445 | 0.790951 | 0.288526 | 0.904650 | 0.535844 |
| LightGBM | 0.889821 | 0.217665 | 0.828212 | 0.344730 | 0.936729 | 0.633026 |

## Key Findings

LightGBM achieved the highest PR-AUC, recall, and precision among the three models. It also delivered the best F1-score and ROC-AUC, indicating that it is the strongest overall performer for this fraud detection task. Both advanced models improved over the baseline SGD Logistic Regression model, with LightGBM showing the largest gain. PR-AUC is particularly important for fraud detection because the data are highly imbalanced and the model must identify rare positive cases while maintaining a useful precision-recall trade-off.

## Preliminary Best Model

Based on the current results, the preliminary best model is LightGBM.

This is still a preliminary selection because later steps will include threshold tuning and explainability analysis.
